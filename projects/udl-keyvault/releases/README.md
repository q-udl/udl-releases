# UDL Key Vault Release Records

This directory stores immutable metadata records for published UDL Key Vault releases.

Create a release record only after the matching APK exists as an immutable asset in `q-udl/udl-releases` and its APK SHA-256, package name, version, and signing-certificate SHA-256 have been verified.

Do not store APK binaries, signing material, passwords, tokens, encryption keys, vault data, or placeholder release records in this directory.
